# GitHub Ruleset 設定ガイド

このドキュメントでは、「**PR経由でのみブランチを更新でき、かつオーナーのみがマージ可能**」なルールセットを GitHub に設定する方法を説明します。

---

## ✅ 目的

- `main` ブランチは **直接push不可**
- **必ずPull Request（PR）経由でのみ変更可能**
- **オーナーのみがPRをマージできる**

---

## 🛠 Ruleset の作成手順

### 1. リポジトリ設定を開く

1. GitHub上でリポジトリのトップページを開く  
2. 上部メニューから `Settings` を選択  
3. 左メニューから `Code and automation` → `Rulesets` をクリック

---

### 2. 新しいルールセットを作成

#### 📌 Ruleset Name

```text
main-branch-protection
```

---

## ✅ Enforcement status

- 有効（オン）にする

---

## 👥 Bypass list

- 自分（オーナー）だけを追加する  
  例：`@your-username`  
- 他のメンバーは追加しない

---

## 🎯 Target branches

- 対象ブランチ：`main`

---

## ✅ 推奨ルール設定（Rules）

| チェック | 内容 |
|---------|------|
| ✅ Require a pull request before merging | PR経由でのみ変更可能にする |
| ✅ Restrict updates | Bypass権限を持つユーザーだけが更新可能（= マージできる） |
| ✅ Block force pushes | `git push --force` を禁止 |
| ✅ Require linear history（任意） | マージコミットを禁止、履歴を直線に保つ |

### オプション（必要に応じて）

- ⬜ Require signed commits
- ⬜ Require status checks to pass
- ⬜ Require deployments to succeed
- ⬜ Require code scanning results

---

## 🔐 Bypass（バイパス）とは？

**バイパス = 保護ルールをスキップできる特別枠**

Bypass list に入っているユーザーだけが、

- PRのマージ
- ブランチの更新/削除
- などの操作を行える

---

## ✅ 最終的な動作

| 操作 | 一般メンバー | オーナー（バイパス権限あり） |
|------|--------------|------------------------------|
| 直接push | ❌ 禁止される | ❌ 禁止される（PR必須） |
| PR作成 | ✅ できる | ✅ できる |
| PRマージ | ❌ 禁止される | ✅ できる |

---

## 📝 備考

- この設定により、チーム開発における安全性と管理性が向上します。
- `Require status checks` を設定すればCI必須にもできます。
