# Cursor ではじめる MCP 開発

公式ドキュメント  
<https://supabase.com/docs/guides/getting-started/mcp?queryGroups=os&os=mac#cursor>

この記事では、**Cursor** から **Supabase MCP サーバー** に接続するまでを、スクリーンショット付きで解説します。

## 1. `.cursor/mcp.json` を作成する

まずはプロジェクト直下に `.cursor/mcp.json` を作成し、以下をペーストします。

```json
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": [
        "-y",
        "@supabase/mcp-server-supabase@latest",
        "--access-token",
        "TODO: Access Token"
      ]
    }
  }
}
```
※ "TODO: Access Token" の部分は後ほど置き換えます。

## 2. Supabase のアクセストークンを取得する

Supabase ダッシュボードの Account ページへ移動
https://supabase.com/dashboard/account/tokens

![](https://storage.googleapis.com/zenn-user-upload/888ea9abc5eb-20250503.png)

![](https://storage.googleapis.com/zenn-user-upload/e2db774947ea-20250503.png)

Generate new token をクリックし、任意の名称を付けてトークンを発行します。
（※発行後は再表示できないため、コピーを忘れずに！）

![](https://storage.googleapis.com/zenn-user-upload/b8e3b39913fe-20250503.png)

## 3. アクセストークンを .cursor/mcp.json に設定する

先ほど発行したトークンで、.cursor/mcp.json の TODO: Access Token を置換します。


## 4. Cursor で Supabase MCP を有効化する
1. Cursor を再起動
2. Settings › MCP へ移動し、Supabase MCP を Enabled に切り替え
3. Status が Connected になれば準備完了です

![](https://storage.googleapis.com/zenn-user-upload/0576c360de45-20250503.png)

## 5. 動作確認

チャット欄で mcp listProjects などを入力してみましょう。
Supabase プロジェクトの一覧が返ってくれば接続成功です。

![](https://storage.googleapis.com/zenn-user-upload/c9aeb0f8c58c-20250503.png)
